Nagar Shield — Report Crime redesign

Review preview only. The app is unchanged. Tap the small i buttons, the Incident type field and the Location tabs to try them. Use the state buttons to see every step.

What changed and why

  • One pattern for every card. Evidence, Incident type, What happened, Location, then Privacy. Every card has the same header: the title, a small i, and one tag on the right (Required, Optional, or the current privacy choice). No numbers.
  • File rules live behind an “i”. The long sentence about file types and sizes is gone from the page. Tap the small i next to Evidence to see the accepted files. Privacy and Location have one too.
  • The description is required. The tag says so, the box has no “optional” wording, and the Send button stays off until something is written. The hint under it says what is missing.
  • Evidence is two clear choices. Take a photo, or record a video. Choosing from the gallery is one button under them. After a file is added the card shows a large preview, its size, a Replace button and a clear Remove button.
  • The Send button is always in view. It stays at the bottom. While something is missing it says what, in one short line.
  • Incident type is a field that opens a list. Every type has its own icon and colour, the same as on the Home feed. “Not sure / skip” is the first choice.
  • Location is detected for the user. A green card names the area and the accuracy, with a Redetect button. “Choose area” is one tap away for anyone who needs it.
  • Every state is designed. Empty, file added, preparing a video, a file error, sending, and saved offline. Errors are short and say what to do.
  • Same system as Home. Same tokens, 20 px gutters, 18 px cards, 14 px tiles, Fluent filled icons, light and dark. Every control is 44 to 56 px tall.
